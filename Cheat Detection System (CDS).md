# **Cheat Detection System (CDS)**

##### 

Problem: Currently gaming industries are growing rapidly but the major problem these industries/games faces in player using cheat (commonly called as HACKED VERSION) or external software to get unfair advantage in game.



Solution: Our this CDS system will detect them using Advance algorithms and Machine learning on the basis of there game performance.

CDS core concept: it view the user performance and history to decide and active anomaly detection while playing these both and filter out and mark the user using cheat methods/Software.





##### The three layers of CDS

there are 3 working layer of CDS that independently identify the cheat users.

1. Passive Detector (NLP method)

   ---
2. Active Detector (Anomaly method)

   ---
3. ###### External verification (Agentic Method)
